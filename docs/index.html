1. Publish tabs as CSV

In your Google Sheet, choose File > Share > Publish to web. Pick the Job Tracker tab as Comma-separated values (.csv) and click Publish. Repeat for the Run Log tab.

2. Insert Published URLs

Open docs/index.html in your editor and paste the URLs into the variables at the top of the <script> block.

3. Push to master

Commit the file and push it. The GitHub Actions build will update your Pages dashboard page automatically in seconds.
